# 📚 Semantic Memory — Knowledge Network

> Facts, concepts, and meanings — stripped of personal context.

## What's stored:
- Vocabulary & language rules
- Facts ("Water boils at 100°C")
- Categories & taxonomies ("A robin is a bird")
- Schemas & scripts ("Restaurant script: enter → seat → order → eat → pay → leave")
- Mathematical & logical rules

## Organization: Concept Network (not folders!)
```
        ┌─── has_feathers ───┐
BIRD ───┼─── can_fly ────────┼── ROBIN (typical)
        ├─── lays_eggs ──────┤
        └─── has_beak ───────┘── PENGUIN (atypical — can't fly)
```
- **Spreading activation**: Thinking "doctor" primes "nurse", "hospital", "stethoscope"
- **Prototype theory**: Categories have "best examples" (robin > penguin for "bird")
- **Schema theory**: Knowledge organized in scripts that guide expectations

## Episodic → Semantic transition:
- You remember LEARNING that Paris is in France (episodic)
- Eventually, you just KNOW it without remembering when you learned it (semantic)
- Consolidation strips away context, keeps the fact

## Most resilient memory type — survives aging better than episodic
