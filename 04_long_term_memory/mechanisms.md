# ⚙️ Long-Term Memory — Mechanisms

## The Molecular Basis of Permanent Storage

### Step 1: Synaptic Tagging (Minutes)
- Active synapses get "tagged" by local protein phosphorylation
- Tag says: "This synapse was recently active and should be strengthened"
- Tag is temporary (~1-2 hours) — needs reinforcement

### Step 2: Gene Expression (Hours)
- Strong/repeated activation → signals reach the nucleus (CREB pathway)
- CREB (transcription factor) activates genes for structural proteins
- mRNA travels back to tagged synapses specifically
- **Critical window**: Protein synthesis inhibitors given within 1-2 hours → memory never consolidates

### Step 3: Structural Remodeling (Hours → Days)
- New AMPA receptors permanently inserted
- Dendritic spines enlarge (more surface area for synapses)
- Entirely new synaptic connections form
- Presynaptic terminal enlarges (more vesicles, more reliable transmission)

### Step 4: Systems Consolidation (Days → Years)
- Hippocampal replay strengthens cortical connections
- Gradually, cortical-cortical links become self-sustaining
- Memory becomes hippocampus-INDEPENDENT
- Final storage: Distributed across neocortex as a pattern of synaptic weights

## How Memories are Physically "Encoded"

### The Engram (Memory Trace):
- A memory = specific pattern of synaptic strengths across a neural ensemble
- Not one neuron, not one synapse — a distributed NETWORK state
- Lashley's search (1950): Couldn't find memory in one place → "engram" is everywhere

### Modern Engram Research (Tonegawa Lab):
- Optogenetically labeled neurons active during fear conditioning
- Later REACTIVATED those exact neurons with light → animal shows fear
- Even in a DIFFERENT context (the memory was artificially triggered)
- Proves: The engram is a real, physical, activatable pattern

## Reconsolidation: Memories Can Be Rewritten

### The Discovery:
1. Memory is recalled → becomes LABILE (unstable) for a few hours
2. During this window: Memory can be modified, strengthened, or weakened
3. Then: Re-stabilizes (reconsolidation)
4. New version becomes the permanent record

### Implications:
- Every time you recall a memory, you subtly CHANGE it
- Memories are not fixed recordings — they're living, editable documents
- Therapeutic application: Recall traumatic memory + intervention → weaken the trace
- Explains why memories drift over time (reconstructive, not reproductive)

## Storage Across Cortical Systems

| Memory Content | Primary Storage Region |
|---------------|----------------------|
| Visual scenes | Occipital + Temporal cortex |
| Sounds | Superior Temporal Gyrus |
| Spatial layouts | Parietal cortex + Hippocampus |
| Motor sequences | Basal Ganglia + Cerebellum |
| Emotional associations | Amygdala + Orbitofrontal |
| Abstract concepts | Prefrontal + Temporal poles |
| Language | Left hemisphere perisylvian areas |

## The 2.5 Petabyte Estimate
- ~86 billion neurons × ~7,000 synapses each ≈ 600 trillion synapses
- Each synapse: ~4.7 bits of information (Bhatt et al., 2015, Salk Institute)
- 600 trillion × 4.7 bits ≈ 2.5 petabytes
- For reference: 2.5 PB = ~500,000 hours of HD video = 2.5 million GB
