# ⚡ Priming — Perceptual Shortcuts

> Prior exposure makes subsequent processing faster — WITHOUT conscious awareness.

## Types:
- **Perceptual priming**: Seeing a word briefly → recognize it faster next time (even if you don't remember seeing it)
- **Semantic priming**: "Doctor" speeds recognition of "Nurse" (spreading activation)
- **Conceptual priming**: Reading about "elderly" → walking slower (behavior priming)

## Key evidence (amnesic patients):
- Cannot remember seeing a word list 5 minutes ago
- BUT: Complete word fragments faster for words that WERE on the list
- Proves: Priming ≠ conscious memory. Different system entirely.

## Duration: Minutes to months (depends on type and repetition)
## Brain basis: Reduced neural firing in sensory/association cortex (repetition suppression)
