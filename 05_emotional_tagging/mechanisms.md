# ⚙️ Emotional Tagging — Mechanisms

## The Amygdala-Hippocampus Circuit

```
     Sensory Input (Threat? Reward? Significance?)
              ↓
     ┌──────────────────┐
     │     AMYGDALA      │  ← Significance detector (~12ms for fear)
     │ (Basolateral BLA) │
     └────────┬──────────┘
              ↓ (modulation signals)
     ┌────────┼────────────────┐
     ↓        ↓                ↓
 HIPPOCAMPUS  CORTEX        HPA AXIS
 (Enhanced    (Enhanced      (Cortisol +
  encoding)    attention)     Norepinephrine)
```

## Two Pathways for Threat Processing

### Low Road (Fast, Imprecise):
- Thalamus → Amygdala directly (~12ms)
- No cortical processing (you react BEFORE you perceive)
- "Shoot first, ask questions later"
- Example: Jump at a stick that looks like a snake

### High Road (Slow, Accurate):
- Thalamus → Cortex → Amygdala (~200ms)
- Full object recognition before emotional response
- "Oh wait, it's just a stick"
- Override the low-road false alarm

## How Emotion Enhances Memory

### 1. Norepinephrine Release (Acute):
- Amygdala activation → Locus Coeruleus → NE flood
- NE in hippocampus: Enhances LTP (synapses strengthen MORE during emotional events)
- NE in cortex: Increases signal-to-noise ratio (everything seems sharper)
- Result: Emotional events get STRONGER initial encoding

### 2. Cortisol Release (Delayed, 15-30 min):
- HPA axis activation → cortisol from adrenal glands
- Moderate cortisol: ENHANCES memory consolidation (works WITH NE)
- High cortisol: IMPAIRS encoding (overwhelms hippocampal receptors)
- Chronic cortisol: DESTROYS hippocampal neurons (toxic at high chronic levels)

### 3. Dopamine Modulation (Reward):
- Unexpected rewards → VTA releases dopamine
- Dopamine in hippocampus: Tags "this is worth remembering"
- Creates "reward prediction error" learning signal
- Positive experiences get priority encoding too (not just threats)

### 4. Consolidation Enhancement:
- Emotional memories get PRIORITY replay during sleep
- More sharp-wave ripple replays for emotionally tagged events
- Amygdala-hippocampal theta coupling during REM → emotional memories consolidated preferentially

```
     ↑        ╱╲

         Low   Optimal   High
         
Moderate stress = BEST memory
Too little = Not encoded (boring)
Too much = Encoding IMPAIRED (overwhelm)
```

## Emotional Memory vs. Memory for Emotion
- **Emotional memory**: You remember the EVENT better because it was emotional
- **Memory for emotion**: You remember HOW YOU FELT (separate storage)
- These dissociate: You can remember an event was emotional without feeling it anymore
- Sleep strips emotional charge while preserving event details (adaptive!)
