# 🔧 Implicit (Non-Declarative) Memory

> What you know but CAN'T verbally explain. Expressed through performance, not recall.

## Key property: Hippocampus-INDEPENDENT
- Amnesic patients (no hippocampus) can still learn these
- Proves these are fundamentally different storage systems

## Subtypes
1. **Procedural** — Motor skills, cognitive skills (riding a bike, typing)
2. **Priming** — Prior exposure speeds processing (subliminal facilitation)
3. **Conditioning** — Stimulus-response links (Pavlov's dog, phobias)
4. **Non-associative** — Habituation (ignoring AC hum), Sensitization (jumpiness after scare)
