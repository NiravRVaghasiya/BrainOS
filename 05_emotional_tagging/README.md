# ❤️‍🔥 Emotional Tagging — The Amygdala

> The brain's "importance flag" — marks experiences for priority encoding and storage.

## Function: Significance Detector + Memory Modulator

The amygdala doesn't store memories itself — it BOOSTS encoding of emotional events
by modulating hippocampal and cortical consolidation.

## Mechanism:
1. Emotional event occurs
2. Amygdala activates → releases norepinephrine + cortisol
3. These stress hormones enhance hippocampal LTP (stronger encoding)
4. Memory is stored with HIGHER fidelity and STRONGER retrieval cues
5. Result: Emotional memories are recalled more vividly and more frequently

## The Inverted-U:
- Moderate stress → ENHANCED memory (important events remembered well)
- Extreme stress → IMPAIRED memory (trauma can cause fragmentation/gaps)
- Chronic stress → Hippocampal atrophy (cortisol is neurotoxic over time)

## Flashbulb Memories:
- Where were you on 9/11? → Vivid, confident recall
- BUT research shows these are just as inaccurate as normal memories
- Amygdala boosts CONFIDENCE and VIVIDNESS, not necessarily ACCURACY

## Fear Conditioning (special case):
- One-trial learning: Single traumatic event → permanent fear response
- Evolutionarily critical: Touch hot stove ONCE → never again
- Extremely hard to extinguish (PTSD persistence)
