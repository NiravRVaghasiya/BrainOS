# 📖 Explicit (Declarative) Memory

> Memories you can consciously access and verbally describe.
> Requires hippocampal encoding. Vulnerable to interference and decay.

## Two Subtypes

| | Episodic | Semantic |
|--|---------|----------|
| What | Personal events | General knowledge |
| Example | "My 10th birthday party" | "Paris is the capital of France" |
| Context | Time + Place + Emotion | Context-free facts |
| Brain region | Hippocampus + Prefrontal | Temporal cortex |
| Vulnerability | Highly susceptible to distortion | More stable once consolidated |
| Formation | Single exposure can suffice | Usually requires repetition |
