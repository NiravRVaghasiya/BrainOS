# ⚙️ Default Mode Network — Mechanisms

## Anatomy of the DMN

```
┌─────────────────────────────────────────────────────────┐
│                DEFAULT MODE NETWORK                       │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  MEDIAL PREFRONTAL CORTEX (mPFC)                        │
│  └→ Self-referential processing ("What do I think?")    │
│                                                          │
│  POSTERIOR CINGULATE CORTEX (PCC)                        │
│  └→ Autobiographical memory & scene construction         │
│                                                          │
│  ANGULAR GYRUS (AG)                                      │
│  └→ Semantic integration & conceptual combination        │
│                                                          │
│  HIPPOCAMPAL FORMATION                                   │
│  └→ Memory retrieval & future simulation (scene building)│
│                                                          │
│  LATERAL TEMPORAL CORTEX                                 │
│  └→ Semantic knowledge access                            │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## Anti-Correlation with Task-Positive Network (TPN)

```
Activity Level:

DMN:  ████████░░░░░░████████░░░░░░████████
TPN:  ░░░░░░░████████░░░░░░░████████░░░░░░
      │         │         │         │
      Rest    Focus     Rest     Focus
      
When DMN is ON → TPN is suppressed (can't focus externally)
When TPN is ON → DMN is suppressed (can't mind-wander)
Toggle speed: ~200-500ms (takes effort to switch)
```

## Functions in Memory

### 1. Memory Consolidation (Background Processing)
- DMN activation during rest → memory replay and integration
- "Incubation" period after studying: DMN works on connecting new to old knowledge
- This is why breaks IMPROVE learning (DMN does integration work)

### 2. Autobiographical Memory Construction
- PCC + Hippocampus: Reconstruct personal past experiences
- mPFC: Add self-referential evaluation ("How did that make ME feel?")
- This construction is CREATIVE (not playback) — uses same regions as imagination

### 3. Future Simulation (Prospection)
- SAME network active for remembering the past AND imagining the future
- Hippocampus provides "building blocks" (recombines elements of past experiences)
- mPFC evaluates: "Would this be good/bad for ME?"
- Evidence: Amnesics who can't remember also can't imagine future scenarios

### 4. Semantic Memory Access
- Angular gyrus + lateral temporal: Accessing general knowledge without external prompts
- "Stream of consciousness" draws on semantic associations
- This feeds creativity (unexpected combinations of stored knowledge)

## Energy Metabolism
- DMN consumes ~20% of brain's total energy (same as focused cognition!)
- "Resting" brain is NOT idle — it's doing DIFFERENT work
- Metabolic cost: ~6 kcal/hour just for DMN operations
- Never fully shuts down (even in light sleep some DMN activity persists)

## Oscillatory Signatures
- DMN operates primarily in alpha (8-12 Hz) and low beta (12-20 Hz) bands
- Theta (4-8 Hz) coupling with hippocampus during memory retrieval
- Gamma bursts during creative insight moments (DMN → sudden TPN switch)
- The alpha rhythm IS partly the DMN's "idling" frequency

## Development Across Lifespan
- **Childhood**: DMN not fully connected (explains difficulty with sustained self-reflection)
- **Adolescence**: DMN connectivity strengthens (increased self-consciousness, rumination)
- **Adulthood**: Mature, flexible switching between DMN and TPN
- **Aging**: DMN connectivity weakens → reduced mind-wandering, less creative insight
- **Meditation**: Practitioners can VOLUNTARILY modulate DMN (reduce activity during focus)
