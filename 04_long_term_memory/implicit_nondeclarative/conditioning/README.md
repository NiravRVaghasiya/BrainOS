# 🔔 Conditioning — Learned Associations

## Classical Conditioning (Pavlov)
- Bell + Food → Salivation
- Eventually: Bell alone → Salivation
- Brain: Amygdala (fear conditioning), Cerebellum (timing)
- Example: Hospital smell → anxiety (if you had bad medical experiences)

## Operant Conditioning (Skinner)
- Behavior + Reward → Behavior strengthened
- Behavior + Punishment → Behavior weakened
- Brain: Basal Ganglia (reward prediction), Dopamine circuits
- Example: Posting on social media → Likes (variable reward) → Compulsive checking

## Why conditioning is hard to extinguish:
- Extinction ≠ erasure. It's a NEW inhibitory learning layered on top.
- The original association remains intact underneath.
- This is why phobias can "relapse" after successful therapy (spontaneous recovery)
