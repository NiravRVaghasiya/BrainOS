# 📅 Episodic Memory — Personal Time Travel

> "Mental time travel" — Re-experiencing events from your past.

## What's stored:
- WHAT happened
- WHERE it happened
- WHEN it happened
- HOW it felt (emotional color)
- WHO was there

## Encoding format: Scene-based, first-person perspective
- Not a video recording — more like a "story skeleton" with key details
- Rich in sensory fragments (the smell, the sound, the light)
- Emotion is part of the encoding (not separate metadata)

## Recall characteristics:
- Reconstructive (fills gaps with schema/expectations)
- Decreases in vividness over time (power-law forgetting curve)
- Emotionally intense events → stronger encoding (flashbulb memories)
- Subject to distortion: misinformation effect, imagination inflation

## Unique to humans?
Debated — but humans are the only species known to mentally project into the FUTURE
using the same episodic system ("prospective memory" / "mental simulation")
