# 🗺️ Visuospatial Sketchpad
The brain's internal "whiteboard" for images, spatial layouts, and navigation.

## What it holds
- Mental images (visualizing a friend's face)
- Spatial relationships (navigating your apartment in the dark)
- Movement tracking (where objects are moving)

## Capacity: ~3-4 objects
## Subcomponents
- **Visual cache** — Stores form and color
- **Inner scribe** — Handles spatial and movement info

## Fun fact
You can rehearse verbal AND visual info simultaneously (different subsystems),
but two visual tasks interfere with each other (shared resource).
