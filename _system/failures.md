# ❌ System Infrastructure — Failures & Disorders

## Vascular Failures (Blood Supply)

### Stroke (Cerebrovascular Accident)
- **Ischemic (87%)**: Blood clot blocks artery → downstream neurons die within minutes
- **Hemorrhagic (13%)**: Blood vessel bursts → pressure damages surrounding tissue
- **Memory impact**: Depends entirely on location
  - Hippocampal stroke → anterograde amnesia
  - PFC stroke → executive/working memory loss
  - Temporal stroke → language loss
- **"Time is brain"**: Each minute without blood flow → 1.9 million neurons die

### Vascular Dementia
- **What**: Multiple small strokes or chronic insufficient blood flow
- **Result**: Step-wise cognitive decline (sudden drops, not gradual like Alzheimer's)
- **Memory pattern**: Executive dysfunction > pure memory loss
- **Prevention**: Manage cardiovascular risk factors (BP, cholesterol, diabetes, smoking)

### Transient Ischemic Attack (TIA) — "Mini-Stroke"
- **What**: Temporary blood flow blockage (resolves in minutes)
- **Result**: Brief neurological symptoms that fully recover
- **Memory impact**: Transient Global Amnesia sometimes caused by posterior circulation TIA
- **Warning**: 15% of TIA patients have a full stroke within 3 months

## Metabolic Failures

### Thiamine Deficiency (Wernicke-Korsakoff Syndrome)
- **Cause**: Chronic alcoholism → B1 (thiamine) deficiency
- **Wernicke phase**: Acute confusion, eye movement problems, ataxia
- **Korsakoff phase**: Permanent anterograde amnesia + confabulation
- **Mechanism**: Mammillary bodies + thalamus necrose (hippocampal circuit destroyed)
- **Irreversible** once Korsakoff develops (prevention: B1 supplementation)

### Hepatic Encephalopathy
- **What**: Liver failure → ammonia crosses BBB → neurotoxicity
- **Result**: Confusion, memory impairment, personality changes, eventual coma
- **Mechanism**: Ammonia disrupts astrocyte function → glutamate/GABA imbalance
- **Reversible**: If liver function restored (treatment: lactulose, rifaximin)

### Hypothyroidism
- **What**: Insufficient thyroid hormone → reduced brain metabolism
- **Result**: "Brain fog", slow processing, poor memory, depression
- **Mechanism**: Thyroid hormone needed for myelin maintenance + neurotransmitter synthesis
- **Reversible**: Thyroid replacement restores cognitive function

## Demyelinating Diseases

### Multiple Sclerosis (MS)
- **What**: Autoimmune attack on myelin sheaths throughout CNS
- **Result**: Signal conduction failures → variable cognitive + motor symptoms
- **Memory impact**: 40-65% of MS patients have cognitive impairment
- **Pattern**: Processing speed and working memory most affected
- **Mechanism**: Demyelinated axons conduct slowly and unreliably → information arrives "garbled"

### Leukodystrophies (Genetic)
- **What**: Inherited disorders of myelin production
- **Result**: Progressive loss of white matter → declining function
- **Example**: Adrenoleukodystrophy (ALD — "Lorenzo's Oil" disease)
- **Onset**: Often childhood → rapid decline

## Neuroinflammation

### Post-COVID Cognitive Impairment ("Brain Fog")
- **Prevalence**: 20-30% of COVID patients at 3+ months
- **Mechanism**: Microglial activation, BBB leakage, neuroinflammation
- **Symptoms**: Memory encoding failures, attention deficits, word-finding difficulty
- **Duration**: Months to years (still being studied)
- **Treatment**: Time, cognitive rehabilitation, potentially anti-inflammatory interventions

### Autoimmune Encephalitis (Anti-NMDA Receptor)
- **What**: Antibodies attack NMDA receptors (the LTP coincidence detectors!)
- **Result**: Psychiatric symptoms → seizures → memory loss → coma
- **Memory mechanism**: If NMDA receptors are blocked → NO LTP → NO new memory formation
- **Critical**: Often misdiagnosed as psychiatric illness initially
- **Treatable**: Immunotherapy (early treatment = better outcome)

## Toxic Exposure

| Toxin | Mechanism | Memory Effect |
|-------|-----------|---------------|
| Lead | Disrupts calcium signaling, NMDA receptor function | Reduced IQ, learning impairment |
| Mercury | Destroys neurons in visual/somatosensory cortex | Processing deficits |
| Alcohol (chronic) | Thiamine depletion + direct neurotoxicity | Korsakoff amnesia |
| Carbon monoxide | Binds hemoglobin → global hypoxia | Hippocampal death → amnesia |
| Organophosphates | Blocks acetylcholinesterase | Acute cholinergic crisis → confusion |
| Chemotherapy ("chemo brain") | Disrupts neurogenesis + causes inflammation | Encoding/attention deficits |

## The Blood-Brain Barrier — When It Fails
- **Normal**: Tight junctions prevent 98% of molecules from entering
- **Failure modes**: Inflammation, hypertension, diabetes, aging, infection
- **When BBB leaks**: Immune cells enter brain → neuroinflammation cascade
- **Chronic BBB failure**: Microbleeds, white matter damage, vascular dementia
- **Protection**: Exercise, blood pressure control, anti-inflammatory diet, sleep
