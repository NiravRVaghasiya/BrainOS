# 🗣️ Phonological Loop
The brain's "inner voice" — rehearses verbal/auditory information.

## Components
1. **Phonological Store** — Holds sound-based traces (~2s decay)
2. **Articulatory Rehearsal** — Refreshes by sub-vocal speech

## Evidence
- Word-length effect: Longer words → fewer remembered (takes longer to rehearse)
- Phonological similarity effect: Similar-sounding words interfere (man, mat, map, cap)
- Articulatory suppression: Say "the the the" → loop is hijacked → verbal memory drops

## Function
- Learning new vocabulary
- Mental arithmetic (holding intermediate results)
- Reading comprehension (buffering phrases)
