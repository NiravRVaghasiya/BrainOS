# ❤️‍🔥 Emotional Modulation of Information Flow

> The amygdala doesn't store memories — it AMPLIFIES or BLOCKS the encoding/retrieval pipeline at every stage.


## Mood-Congruent Memory (Retrieval Bias)

```
CURRENT MOOD acts as a retrieval filter:

HAPPY MOOD ──→ Retrieval cue biased toward:
                ├── Positive past events
                ├── Successes and achievements  
                ├── Warm social memories
                └── Optimistic future projections
                
SAD MOOD ──→ Retrieval cue biased toward:
                ├── Losses and failures
                ├── Negative social interactions
                ├── Missed opportunities
                └── Catastrophic future projections

The SAME memory network exists — but current mood determines 
WHICH ENTRY POINTS are activated for retrieval.
This creates self-reinforcing cycles (depression spiral / gratitude spiral).
```

## Special Case: Traumatic Memory Encoding

```
NORMAL ENCODING:                  TRAUMATIC ENCODING:
━━━━━━━━━━━━━━━━                  ━━━━━━━━━━━━━━━━━━━━
Sequential                        FRAGMENTED
Coherent narrative                 Sensory fragments (smell, sound, image)
Context-bound (past tense)         Context-FREE (feels "now")
Hippocampus-integrated             Hippocampus OVERWHELMED
Prefrontal regulates               Prefrontal OFFLINE (dissociation)
                                   
Result: Complete, datestamped      Result: Sensory shards without
        episode stored normally            time/place context
                                           
Recall: "I remember that day..."   Recall: "I AM there again" (flashback)
        (Past, controlled)                  (Present tense, uncontrolled)
```

**Why trauma memories intrude:**
The hippocampus normally stamps memories with time/place context ("This happened THEN, not NOW"). In extreme stress, hippocampal processing is disrupted. The memory is stored as raw sensory fragments WITHOUT temporal context. So when any fragment is triggered → it activates WITHOUT the "this is past" tag → experienced as happening NOW.
