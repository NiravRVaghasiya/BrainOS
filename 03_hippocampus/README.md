# 🏗️ Hippocampus — The Memory Indexer

> Not where memories are stored — where they are ROUTED, INDEXED, and CONSOLIDATED.

## Role: Memory's Search Engine + File System Manager

Think of it as:
- **Google Index** (not the web pages themselves)
- **Library catalog** (not the books)
- **RAM-to-SSD transfer manager** (moves temporary → permanent)

## Key Functions

### 1. Pattern Separation
Take similar experiences and store them distinctly.
- Monday's parking spot vs Tuesday's → different memory traces
- Without this: All similar events blur together (source confusion)

### 2. Pattern Completion
Partial cue → full memory retrieval.
- Smell of grandmother's cookies → entire kitchen scene reconstructed
- First few notes of a song → whole melody plays in your mind

### 3. Consolidation (Temporary → Permanent)
- New memories are hippocampus-DEPENDENT for days/weeks
- Over time, connections strengthen in neocortex → hippocampus-INDEPENDENT
- This is why brain damage to hippocampus erases RECENT memories but spares OLD ones (Ribot's Law)

## The Famous Case: Patient H.M.
- Hippocampus removed bilaterally (1953, for epilepsy)
- Could NOT form new explicit memories (anterograde amnesia)
- Old memories were mostly intact
- COULD still learn new motor skills (procedural memory = different system!)
- Proved: Hippocampus = gateway to long-term declarative storage
