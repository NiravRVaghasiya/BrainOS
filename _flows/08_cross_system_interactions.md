## Key Cross-System Interactions

### 1. Prefrontal ↔ Hippocampus (Executive-Memory Dialogue)

```
PFC → HIPPOCAMPUS:
├── "Search for THIS" (strategic retrieval cue generation)
├── "Encode THIS" (top-down attention directs what's stored)
├── "Suppress THAT" (motivated forgetting, retrieval stopping)
└── "Update your index" (working memory determines what's worth indexing)

HIPPOCAMPUS → PFC:
├── "Here's what I found" (retrieval output enters working memory)
├── "This is NEW" (novelty/mismatch signal for prediction error)
├── "Context says..." (environmental cue activates relevant memories)
└── "Compare these" (pattern separation output for decision-making)

SYNCHRONIZED VIA: Theta oscillations (4-8 Hz)
• PFC and hippocampus lock into theta synchrony during encoding AND retrieval
• Stronger theta coupling = better memory performance
• Disrupted by: Stress, sleep deprivation, alcohol, schizophrenia
```

### 2. Amygdala ↔ Hippocampus (Emotion-Memory Coupling)

```
AMYGDALA → HIPPOCAMPUS:
├── Norepinephrine release → enhances LTP (stronger encoding)
├── "Tag this as important" → priority for consolidation
├── Theta synchronization → coordinated encoding of emotional events
└── During fear: Can BYPASS hippocampus → direct fear conditioning

HIPPOCAMPUS → AMYGDALA:
├── Context information → "Is this situation similar to a PAST threat?"
├── Safety signals → "We've been here before and it was fine"
├── Extinction learning → "The cue no longer predicts danger"
└── Pattern completion → "This partial cue matches that scary event"

CLINICAL IMPORTANCE:
• PTSD: Hippocampal context fails → amygdala fires without "it's safe now" signal
• Anxiety: Hippocampus overgeneralizes → too many contexts trigger amygdala
• Extinction therapy: Strengthens hippocampus → amygdala "it's safe" pathway
```

### 4. Basal Ganglia ↔ Prefrontal Cortex (Gate Control)

```
BASAL GANGLIA → PREFRONTAL CORTEX:
┌────────────────────────────────────────────────────────┐
│                                                         │
│  DEFAULT STATE: Basal ganglia INHIBITS thalamus         │
│  (Gate = CLOSED)                                        │
│  → PFC contents are PROTECTED from interference         │
│                                                         │
│  DOPAMINE SIGNAL: "Something relevant detected!"        │
│  (Gate = OPENS briefly)                                 │
│  → New information enters PFC (updates working memory)  │
│  → Old contents may be displaced                        │
│                                                         │
│  GATE CLOSES again                                      │
│  → New contents now protected                           │
│                                                         │
│  DYSFUNCTION:                                           │
│  • Too much dopamine → Gate too open → DISTRACTIBILITY  │
│    (everything gets in — ADHD, mania)                   │
│  • Too little dopamine → Gate too closed → RIGIDITY     │
│    (can't update — Parkinson's cognitive symptoms)       │
│                                                         │
└────────────────────────────────────────────────────────┘
```

### 5. Cerebellum ↔ Everything (The Universal Smoother)

```
Traditional view: Cerebellum = motor coordination only
Modern view: Cerebellum optimizes ALL brain processes

CEREBELLUM ↔ MOTOR CORTEX:
  Smooths movement execution, corrects timing errors

CEREBELLUM ↔ PREFRONTAL CORTEX:
  Smooths COGNITIVE sequencing (planning, working memory manipulation)
  Damage → "Cerebellar Cognitive Affective Syndrome"

CEREBELLUM ↔ LANGUAGE AREAS:
  Smooths speech timing and verbal fluency
  Damage → Dysarthria + cognitive linguistic issues

CEREBELLUM ↔ LIMBIC SYSTEM:
  Modulates emotional responses (smoothing emotional regulation)
  Damage → Inappropriate emotional responses

GENERAL PRINCIPLE:
The cerebellum builds INTERNAL MODELS of any process and provides
PREDICTIVE CORRECTIONS. This applies to motor, cognitive, linguistic,
and emotional processes equally.
```

## The Information Flow During a Complete Experience

```
EXAMPLE: "You're walking and suddenly smell your ex's perfume"

T=0ms:    OLFACTORY CORTEX detects familiar scent
          (Unique: smell BYPASSES thalamus → direct to cortex + amygdala)
          
T=12ms:   AMYGDALA flags significance (emotional association detected)
          → Norepinephrine released → attention captured
          
T=100ms:  HIPPOCAMPUS begins pattern completion
          Partial cue (smell) → activates linked episode:
          [person + place + emotion + visual + conversation]
          
T=200ms:  CORTEX reactivation begins
          Visual cortex: face of ex
          Auditory cortex: their voice
          Somatosensory: feeling of embrace
          Prefrontal: Interpretation ("This reminds me of...")
          
T=300ms:  WORKING MEMORY holds reconstructed episode
          PFC evaluates: "Is this a pleasant or painful memory?"
          
T=400ms:  DMN activates (if not in focused task)
          Begins elaboration: "I wonder what they're doing now..."
          Future simulation: "What if I ran into them?"
          
T=500ms+: BEHAVIORAL OUTPUT
          Basal ganglia: Approach or avoid response
          Motor system: Turn head toward scent source? Walk away?
          Language: Inner speech ("Wow, that took me back...")
          
SIMULTANEOUSLY: Amygdala modulating everything:
          → Encoding THIS moment with emotional enhancement
          → The experience of being reminded is ITSELF being memorized
          → Reconsolidation: Original memory is now MODIFIED by this re-encounter

Total elapsed: ~500ms from smell to full conscious experience + behavioral response
All systems talking to each other in parallel, not sequential
```
