# 🔬 Language Networks — Real-World Examples

## The Speed of Language Processing

### 1. You Process 3-5 Words Per Second in Conversation
- Average speech: 150 words/minute
- For EACH word: Phonological recognition + lexical access + syntactic integration + semantic composition
- All of this happens in ~200-400ms per word
- You're not aware of any of this effort — it's fully automated

### 2. Tip-of-the-Tongue (Lexical Access Failure)
- "It starts with a P... it's a type of fabric... POLYESTER!"
- You have partial access: First letter, number of syllables, meaning
- Proves: Word representations have multiple independently accessible layers
- Resolves spontaneously when the right phonological activation threshold is crossed

## Language and Memory Interplay

### 3. The Bilingual Advantage
- Bilinguals constantly inhibit one language while using the other
- This exercises executive control → better working memory performance
- "Language switching cost": 200-300ms to shift between languages
- Both languages are ALWAYS active (even the "off" one primes semantically)

### 4. Verbal Overshadowing
- See a face → describe it in words → WORSE at picking it from a lineup
- Verbal encoding INTERFERES with visual memory
- Words impose categorical structure on continuous visual information
- Language shapes memory (not just reports it)

### 5. Deaf Signers: Language Without Sound
- Sign language activates the SAME left hemisphere regions (Broca's + Wernicke's)
- Proves: Language networks are modality-independent (abstract linguistic computation)
- Broca's area = grammar engine, regardless of output modality (mouth or hands)

## Storage of Linguistic Knowledge

### 6. The "Mental Dictionary" Size
- Average adult: 20,000-35,000 word families (60,000-100,000 total forms)
- Shakespeare used ~31,000 unique words
- You recognize a word in ~200ms (faster than you can recognize a face!)
- Frequency effect: Common words accessed faster (logarithmic relationship)

### 7. Semantic Priming in Everyday Life
- Hearing "doctor" makes you process "nurse" 50ms faster
- Context constrains which meaning activates: "bank" after "river" vs "money"
- You effortlessly process 5-6 meanings per second (disambiguation is automatic)

### 8. Children's Language Explosion (18-24 months)
- From ~50 words to 500+ words in 6 months ("vocabulary spurt")
- Learning ~10 new words per DAY (fast mapping via hippocampus)
- Grammar emerges simultaneously: Word order, morphology, recursion
- No explicit teaching needed — procedural system extracts rules from exposure

## When Language Networks Disconnect

### 9. Broca's Aphasia (Non-fluent)
- "Want... go... store... bread"
- COMPREHENSION intact (understands everything)
- PRODUCTION impaired (can't assemble grammatical sentences)
- Content words preserved, function words ("the", "is", "to") lost
- Proves: Grammar production ≠ comprehension (different circuits)

### 10. Wernicke's Aphasia (Fluent)
- "I went to the glimber and there was a frothing glibbet on the wonker"
- Fluent speech with normal grammar and prosody
- But MEANING is absent (word salad, neologisms)
- Patient doesn't realize they're not making sense
- Proves: You can produce syntactically perfect sentences with zero semantic content
