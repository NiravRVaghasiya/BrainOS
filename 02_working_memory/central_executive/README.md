# 🎯 Central Executive (Attention Director)
The CEO of working memory — decides what to focus on, what to suppress, and what to act on.

## Functions
1. **Selective attention** — Focus on relevant, ignore distractions
2. **Task switching** — Shift between mental tasks (costly — "switch tax")
3. **Updating** — Replace old info with new (saw a price change → update plan)
4. **Inhibition** — Suppress prepotent responses (don't blurt out, don't look at distraction)

## Located: Dorsolateral Prefrontal Cortex (DLPFC)
## Develops: Last brain region to fully myelinate (~age 25)
## Most affected by: Sleep deprivation, stress, alcohol, aging
