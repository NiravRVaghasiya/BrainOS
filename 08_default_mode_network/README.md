# 💭 Default Mode Network (DMN)

> What the brain does when it's "doing nothing" — and it's NOT nothing.

## Active during:
- Daydreaming / Mind-wandering
- Self-referential thought ("What do I think about this?")
- Remembering the past (episodic recall)
- Imagining the future (prospection / simulation)
- Theory of mind (thinking about others' thoughts)
- Creative insight / incubation

## Regions:
- Medial Prefrontal Cortex (self-reference)
- Posterior Cingulate Cortex (autobiographical memory)
- Angular Gyrus (semantic integration)
- Hippocampus (scene construction)

## Why it matters for memory:
1. **Memory consolidation** — DMN activity helps integrate new memories with existing knowledge
2. **Creative connections** — Loose, wandering activation finds non-obvious links between ideas
3. **Future planning** — Uses episodic memory system "in reverse" to simulate future scenarios

## The DMN is NOT "idle":
- Consumes ~20% of brain's energy (same as focused attention!)
- Suppressed during focused external tasks (task-positive network takes over)
- Alternation between DMN and task-positive = healthy cognition
- Inability to suppress DMN → rumination, ADHD-like symptoms
