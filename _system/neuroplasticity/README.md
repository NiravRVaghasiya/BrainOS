# 🔄 Neuroplasticity — The Brain Rewires Itself

> The biological basis of ALL learning and memory.

## Types:

### Synaptic Plasticity (minutes → hours)
- **LTP** (Long-Term Potentiation): "Neurons that fire together, wire together" (Hebb's Rule)
- **LTD** (Long-Term Depression): Weak/unused connections weaken
- Mechanism: NMDA receptors detect coincident firing → insert more AMPA receptors → stronger synapse

### Structural Plasticity (hours → days)
- New dendritic spines grow
- Axon terminals enlarge
- Entirely new synapses form
- Requires protein synthesis (why consolidation takes time)

### Network Plasticity (weeks → months)
- Entire circuits reorganize
- Cortical maps expand (London taxi drivers → larger hippocampus)
- Cross-modal plasticity (blind people's visual cortex processes touch/sound)

## Critical periods vs. lifelong plasticity:
- Childhood: Explosive plasticity (language, vision, social bonds)
- Adulthood: Still plastic, but requires MORE effort and repetition
- Key: Plasticity never reaches zero — the brain can ALWAYS learn

## What enhances plasticity:
- Exercise (BDNF release — "miracle-gro for the brain")
- Sleep (consolidation window)
- Novelty and challenge (forces adaptation)
- Social interaction (complex multi-modal stimulation)
