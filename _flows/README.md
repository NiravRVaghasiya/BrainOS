# 🔀 Information Flow Pathways

> How information moves BETWEEN brain systems — from first contact to permanent storage to recall.

## The Three Master Flows

```
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                          │
│  ENCODING          CONSOLIDATION           RETRIEVAL                     │
│  (Input → Store)   (Temporary → Permanent) (Store → Output)             │
│                                                                          │
│  Sensory Buffer    Hippocampus replays     Cue activates partial pattern │
│       ↓            during sleep                 ↓                        │
│  Attention Gate         ↓                  Hippocampus completes pattern │
│       ↓            Cortex strengthens           ↓                        │
│  Working Memory    connections             Reconstruction in WM          │
│       ↓                 ↓                       ↓                        │
│  Hippocampus       Independence from       Conscious experience          │
│  (indexes it)      hippocampus             (or automatic behavior)       │
│                                                                          │
└─────────────────────────────────────────────────────────────────────────┘

```
