# 🗑️ Forgetting — A Feature, Not a Bug

> Forgetting is ACTIVE, ADAPTIVE, and ESSENTIAL for efficient cognition.

## Why forgetting exists:
1. **Interference reduction** — Old irrelevant memories would clutter retrieval
2. **Generalization** — Forgetting details allows extraction of patterns/rules
3. **Updating** — Old info (moved address, changed password) must be overridden
4. **Emotional regulation** — Reducing emotional charge of painful memories

## Mechanisms:

### Decay (Passive)
- Synaptic connections weaken without reactivation
- Ebbinghaus forgetting curve: ~50% lost in 1 hour, ~70% in 24 hours (without review)

### Interference (Active)
- **Proactive**: Old memories disrupt new learning (old phone number blocks new one)
- **Retroactive**: New learning disrupts old memories (new password makes you forget old one)

### Motivated Forgetting
- **Suppression** (conscious): Deliberately not thinking about something
- **Repression** (unconscious): Traumatic memories pushed below awareness (controversial)

### Retrieval-Induced Forgetting
- Practicing retrieval of SOME items weakens memory for RELATED but unpracticed items
- Studying Topics A, B, C then being tested only on A → B and C become HARDER to recall

## The forgetting curve can be defeated:
- **Spaced repetition** — Review at expanding intervals (1d, 3d, 7d, 14d, 30d...)
- **Active recall** — Testing yourself is FAR more effective than re-reading
- **Elaborative encoding** — Connect to existing knowledge → more retrieval routes
- **Sleep** — Consolidation stabilizes against decay

## Pathological forgetting:
- Alzheimer's: Hippocampal death → can't consolidate new memories
- Amnesia: Encoding failure (anterograde) or retrieval failure (retrograde)
- PTSD: FAILURE to forget — emotional memories remain hyperactive
