# 🔬 Working Memory — Real-World Examples

## Everyday Demonstrations

### 1. Phone Number Retention
- Someone tells you: "Call me at 555-0147"
- You repeat it mentally (phonological loop)
- If interrupted before dialing → lost (no consolidation, no rehearsal)
- Chunking helps: "555" + "01" + "47" = 3 chunks instead of 7 digits

### 2. Mental Arithmetic
- "What's 23 × 17?"
- Must hold 23, 17, partial products (161 + 230) simultaneously
- Central executive coordinates: multiply → hold → add
- Why harder without paper: Paper offloads storage, freeing executive resources

### 3. Following Directions
- "Go past the bank, turn left at the light, then second right after the school"
- Visuospatial sketchpad: Building mental map in real-time
- Phonological loop: Holding the verbal sequence
- Central executive: Integrating both + executing steps

### 4. Reading Comprehension
- "The dog that the cat that the rat bit chased ran away"
- Must hold all nested clauses simultaneously to parse meaning
- When WM is overloaded → re-read (you literally ran out of processing space)
- Center-embedded sentences kill comprehension at depth 3+

### 5. Cooking a Complex Recipe
- Timer on pasta (phonological rehearsal of time)
- Spatial tracking of multiple pots/pans (visuospatial)
- Deciding what to do next (executive)
- Integrating taste memory with current progress (episodic buffer)

## Expert Performance (Chunking Expansion)

### 6. Chess Masters
- Can recreate a mid-game board from 5-second exposure (~25 pieces correctly)
- Novices: ~4-5 pieces
- NOT more WM capacity — same ~4 chunks, but each chunk = an entire strategic configuration
- Scramble the board randomly → experts perform like novices (chunks don't apply)

### 7. Musicians Sight-Reading
- Reading ahead while playing current notes
- Phonological loop holds upcoming notes
- Motor programs execute current passage automatically
- WM frees up because procedural memory handles execution

### 8. Simultaneous Interpreters
- Listen in Language A (phonological store)
- Translate mentally (central executive)
- Speak in Language B (articulatory output)
- All three happen SIMULTANEOUSLY — extreme WM training

## Capacity Tests

### 9. N-Back Task
- See a sequence of letters: A - B - C - B - D - C...
- "2-back": Press button when current letter matches the one 2 positions ago
- Requires continuous updating (replacing old items with new ones)
- Performance degrades sharply beyond 3-back for most people

### 10. Operation Span Task (OSPAN)
- Solve: (3 × 4) - 2 = ? TRUE/FALSE
- Remember: "DOG"
- Repeat 3-7 times, then recall all words in order
- Measures WM under concurrent processing load
- Strong predictor of: fluid intelligence, reading comprehension, reasoning ability
