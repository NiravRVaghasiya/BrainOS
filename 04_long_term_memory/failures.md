# ❌ Long-Term Memory — Failures & Disorders

## Encoding Failures (Never Stored Properly)

### Shallow Processing
- **What**: Information processed only at surface level never reaches LTM
- **Example**: Reading a textbook page while thinking about dinner → no trace formed
- **Fix**: Levels of processing — deeper encoding (meaning, connection, elaboration) = stronger trace

### Divided Attention at Encoding
- **What**: Multitasking during learning cuts encoding quality by 50%+
- **Mechanism**: Hippocampal encoding requires focused attention; competition splits resources
- **Evidence**: Students who multitask during lectures recall 50% less

### Encoding Specificity Failure
- **What**: Available cues at retrieval don't match encoding context
- **Example**: Studied in silence → tested in noisy room → recall drops
- **Fix**: Vary study contexts OR match test conditions

## Storage Degradation (Memories Fade or Change)

### Ebbinghaus Forgetting Curve
```
100% ─────╮
           ╰──────╮
                    ╰────────────────────────────── ~20% after 30 days
                    
    0h   1h   1d    1w     1mo
    
Without intervention: 56% lost in 1 hour, 66% in 1 day, 75% in 6 days
```

### Memory Distortion (Misinformation Effect)
- **Loftus & Palmer (1974)**: "How fast were the cars going when they [smashed/hit/contacted]?"
- **"Smashed"** group estimated higher speed AND later "remembered" broken glass (there was none)
- Memory was ALTERED by post-event information
- Implications: Eyewitness testimony is deeply unreliable

### Source Monitoring Failure
- **What**: Remember the content but not WHERE you learned it
- **Example**: "I know this fact... did I read it? Did someone tell me? Did I dream it?"
- **Dangerous**: You might attribute your own idea to someone else, or vice versa
- **Increases with age**: Temporal/source tags degrade faster than content

## Retrieval Failures (It's There But You Can't Get It)

### Retrieval-Induced Forgetting
- **What**: Practicing retrieval of some items SUPPRESSES related but unpracticed items
- **Example**: Studying Chapters 1, 2, 3 then being quizzed only on 1 → Chapters 2 & 3 become HARDER to recall
- **Mechanism**: Inhibitory processes suppress competitors during selective retrieval
- **Adaptive**: Keeps current info accessible, suppresses outdated

### Cue-Dependent Forgetting
- **What**: Memory exists but no retrieval path reaches it
- **Example**: Can't remember a high school classmate's name until you see a yearbook photo
- **The memory isn't "gone"** — it just needs the right cue to activate the network

## Clinical Disorders

### Alzheimer's Disease (Progressive LTM destruction)
- **Stage 1**: Recent episodic memory fails (hippocampus dies first)
- **Stage 2**: Semantic memory degrades (can't name objects)
- **Stage 3**: Procedural memory fails (can't dress self)
- **Stage 4**: All memory systems collapse
- **Mechanism**: Amyloid plaques + tau tangles → neuronal death spreading from hippocampus outward

### Dissociative Amnesia (Psychogenic)
- **What**: Sudden inability to recall autobiographical information, usually after trauma
- **Mechanism**: NOT neural damage — psychological blocking of retrieval
- **Difference from organic**: Usually recovers (the memories are intact, just inaccessible)
- **Controversial**: Some question whether true repression exists

### Confabulation (False Memory Production)
- **What**: Generating detailed, confident "memories" of events that never occurred
- **Cause**: Frontal lobe damage → can't monitor/filter memory output
- **Not lying**: Patient genuinely believes the confabulated memory is real
- **Seen in**: Korsakoff's syndrome, TBI, frontal dementia

## Interference

### Proactive Interference (Old blocks new)
- Old Spanish vocabulary makes it harder to learn Italian vocabulary
- Previous phone number intrudes when dialing new one
- Worse when material is SIMILAR (same category, same context)

### Retroactive Interference (New blocks old)
- Learning Italian vocabulary makes it harder to recall previously learned Spanish
- New password makes you forget old password
- This is why "cramming" multiple similar subjects back-to-back is inefficient

## The Forgetting Paradox
> Forgetting is necessary for good memory:
> - Without forgetting: Can't update outdated information
> - Without forgetting: Retrieval becomes impossibly slow (too many candidates)
> - Without forgetting: Can't generalize (every tree looks unique, not "tree-like")
> - PTSD is partly a disorder of FAILED forgetting
