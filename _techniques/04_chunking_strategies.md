# 🧱 Chunking — Expanding Working Memory Capacity

> You can't hold more than ~4 items in working memory. But you can make each "item" HUGE.

## The Neuroscience Behind It

### Why Chunking Works:

**1. WM Capacity is Slot-Limited, Not Information-Limited**
- 4 slots (theta-gamma coupling)
- Each slot can hold: 1 digit OR 1 entire chess position (if you're an expert)
- Chunking compresses multiple items into one "unit" that fits in a single slot

**2. Chunks Live in Long-Term Memory**
- A chunk = a familiar pattern stored in LTM
- Working memory holds a POINTER to the LTM chunk (not the raw data)
- More expertise = bigger chunks = effectively more capacity for that domain

**3. The Hierarchy Effect**
- Chunks can contain sub-chunks (recursive)
- "FBI" = 1 chunk (containing 3 letters)
- A chess master's "King's Indian Defense" = 1 chunk (containing 15+ piece positions)

## Chunking Strategies by Domain

### 1. Numbers
```
UNCHUNKED: 1 4 9 2 1 0 6 6 (8 items → exceeds WM)
CHUNKED:   1492 - 1066      (2 chunks: Columbus, Battle of Hastings)

UNCHUNKED: 8 0 0 5 5 5 0 1 4 7  (10 items → impossible)
CHUNKED:   800 - 555 - 0147      (3 chunks: area code, exchange, number)

STRATEGY: Find MEANING in number groups
  • Dates (1776, 2001, 1984)
  • Ages (your age, a friend's age)
  • Prices ($4.99, $19.95)
  • Patterns (repeated digits, sequences)
```

### 2. Text / Vocabulary
```
UNCHUNKED: H-I-P-P-O-C-A-M-P-U-S (11 letters → impossible)
CHUNKED:   HIPPO + CAMPUS           (2 meaningful units → easy)

UNCHUNKED: P-N-E-U-M-O-N-O-U-L-T-R-A-M-I-C-R-O-S-C-O-P-I-C-...
CHUNKED:   PNEUMONO + ULTRA + MICRO + SCOPIC + SILICO + VOLCANO + 
           CONI + OSIS (8 meaningful morphemes)

STRATEGY: Decompose into known morphemes, roots, prefixes, suffixes
```

### 3. Processes / Procedures
```
UNCHUNKED (17 steps to prepare a patient):
  Check ID, verify allergies, take BP, check temp, review meds,
  confirm procedure, mark site, check consent, ...

CHUNKED (4 phases):
  VERIFY (ID, allergies, consent, procedure) → 1 chunk
  MEASURE (BP, temp, O2 sat, weight) → 1 chunk
  PREPARE (mark site, position, prep skin, drape) → 1 chunk
  READY (timeout, instruments, team brief, begin) → 1 chunk
  
4 chunks = within WM capacity. Each phase expands to details.
```

### 4. Music
```
UNCHUNKED: C-E-G-C-E-G-C-E-G-B-D-F-B-D-F-B-D-F (18 notes)
CHUNKED:   [C major arpeggio × 3] + [G7 arpeggio × 3] (2 chunks)

Expert pianists chunk entire PHRASES (4-8 bars) as single units.
Each phrase = one WM slot during performance.
```

### 5. Programming / Technical
```
UNCHUNKED: for(int i=0; i<array.length; i++) { sum += array[i]; }
CHUNKED:   "sum all elements in array" (1 concept for an expert)

Expert programmers hold ENTIRE design patterns as single chunks:
  "Singleton" = 1 chunk (but 30+ lines of code)
  "Observer pattern" = 1 chunk (but multiple classes)
```

## Building Expert Chunks (Deliberate Practice)

```
NOVICE sees:       r1-e4  e7-e5  g1-f3  b8-c6  f1-b5
                   (5 separate moves — fills WM)

EXPERT sees:       "Ruy Lopez opening"
                   (1 chunk — learned from 1000s of games)

TO BUILD CHUNKS:
  1. Encounter the pattern many times in different contexts
  2. Name it (naming creates a handle for the chunk)
  3. Practice recognizing it quickly
  4. Practice using it in context
  5. Eventually: Recognition is instant and automatic (LTM access)
  
TIME: 100s to 1000s of exposures to build a truly automatic chunk
      This is what "deliberate practice" builds over years of expertise.
```

## Chunking + Working Memory = Effective Learning

```
GOAL: Reduce cognitive load during learning

METHOD:
  1. PRE-CHUNK before studying complex material:
     Learn vocabulary/terminology FIRST (each term = 1 chunk)
     Then: Complex explanations use familiar chunks instead of raw elements
     
  2. SCAFFOLD from simple to complex:
     Learn sub-skills individually (each becomes a chunk)
     Then: Combine sub-skills (chunked) into larger procedures
     
  3. USE ACRONYMS for lists:
     ROY G. BIV (colors), HOMES (Great Lakes), PEMDAS (math order)
     Each acronym = 1 WM slot containing multiple items
     
  4. NARRATIVE CHUNKING for sequences:
     Create a STORY that links items (story = 1 chunk with embedded order)
     "The KING (K) went to the QUEEN (Q) who was playing ROOK-ing chair..."
```
