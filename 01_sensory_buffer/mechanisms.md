# ⚙️ Sensory Buffer — Mechanisms

## Neural Substrate

### Visual (Iconic) Buffer
- **Location**: Primary Visual Cortex (V1) + retinal persistence
- **Mechanism**: Photoreceptor after-discharge + V1 reverberation
- **Decay**: Rapid phosphorylation deactivates rhodopsin → signal dies in ~250ms
- **Why it exists**: Retinal image fades between saccades (3–4 per second). Buffer provides continuity.

### Auditory (Echoic) Buffer
- **Location**: Primary Auditory Cortex (A1) + Superior Temporal Gyrus
- **Mechanism**: Tonotopic neural loops sustain frequency-specific activation
- **Decay**: Slower than visual (~3–4s) because auditory info is inherently temporal (need the full sequence to parse phonemes, words)
- **Why longer**: You can't "glance" at sound — meaning requires duration

### Tactile (Haptic) Buffer
- **Location**: Primary Somatosensory Cortex (S1)
- **Mechanism**: Meissner's and Merkel cells maintain firing for ~2s after stimulus offset
- **Habituation**: Constant stimuli (clothing, chair pressure) are actively suppressed at thalamic gate

## The Attention Gate (Thalamic Filtering)

```
ALL sensory input
        ↓
  ┌─────────────┐
  │   THALAMUS   │  ← Relay station (except smell, which bypasses)
  │  (Gate/Filter)│
  └──────┬───────┘
         ↓
  Prefrontal "spotlight" selects:
  ┌──────────────────────────────┐
  │ ATTENDED stimuli → Working    │
  │ UNATTENDED → decays instantly │
  └──────────────────────────────┘
```

## Capacity vs. Access
- **Capacity**: Enormous (entire visual field, continuous audio stream)
- **Access**: Severely bottlenecked by attention bandwidth (~4 items/channels)
- **The illusion**: You feel you see "everything" because any spot you check IS there (for ~250ms)
- **Reality**: Unattended items are never encoded beyond this buffer

## Key Neurotransmitters
- **Glutamate**: Maintains the raw signal in sensory cortex
- **Acetylcholine**: Modulates which signals get boosted toward attention
- **GABA**: Suppresses irrelevant/habituated signals (noise gate)
