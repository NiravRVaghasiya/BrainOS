# 🔀 Pattern Separation (Dentate Gyrus)

## Problem: Similar inputs need distinct memory traces
- Where you parked TODAY vs. YESTERDAY (same lot, different spots)
- What your coworker said THIS morning vs. LAST Monday

## Solution: Orthogonalization
The dentate gyrus takes overlapping input patterns and maps them to 
maximally distinct neural representations — even small differences 
get amplified into separate codes.

## When it fails:
- Aging (dentate gyrus is vulnerable) → Source confusion ("Did I take my pill today or was that yesterday?")
- PTSD → Overgeneralization (any loud sound → full trauma response)
