# 🗣️ Language Networks

> Language is stored across a distributed network, not in a single "language center."

## Classic Model (simplified):

```
WERNICKE'S AREA                    BROCA'S AREA
(Posterior temporal)               (Inferior frontal)
┌──────────────────┐               ┌──────────────────┐
│  Comprehension   │──── Arcuate ──│   Production     │
│  Word meanings   │    Fasciculus  │   Grammar        │
│  Sentence parsing│               │   Articulation   │
└──────────────────┘               └──────────────────┘
```

## Modern understanding (much more distributed):
- **Lexicon** (vocabulary) → Middle temporal gyrus
- **Syntax** (grammar rules) → Broca's area + basal ganglia
- **Semantics** (meaning) → Widely distributed (embodied cognition)
- **Phonology** (sound patterns) → Superior temporal + motor cortex
- **Pragmatics** (social context) → Right hemisphere + prefrontal

## Key insight: Language IS memory
- Every word you know = a stored association (sound ↔ meaning ↔ context)
- Grammar = procedural memory (implicit rules learned through exposure)
- Learning a new language = building an entire parallel network
