# 🖥️ Working Memory (Prefrontal Cortex)

> The brain's RAM — your conscious workspace. Small, temporary, energy-expensive.

## Baddeley's Model (Updated)

```
┌─────────────────────────────────────────────┐
│           CENTRAL EXECUTIVE                  │  ← Attention director
│         (Prefrontal Cortex)                  │
├──────────────┬──────────────┬───────────────┤
│ Phonological │  Episodic    │ Visuospatial  │
│    Loop      │   Buffer     │  Sketchpad    │
│ (verbal      │ (integrates  │ (visual/      │
│  rehearsal)  │  all sources)│  spatial)     │
└──────────────┴──────────────┴───────────────┘
```

## Capacity: 4 ± 1 chunks (Miller revised)
- Not 7 items — that's with chunking
- A "chunk" can be 1 digit or 1 complex concept (depending on expertise)
- Chess masters store board positions as chunks — that's why they remember more

## Duration: 15–30 seconds without rehearsal

## Key Mechanisms
1. **Rehearsal Loop** — Subvocal repetition keeps items alive (repeating a phone number)
2. **Chunking** — Group items into meaningful units (FBI-CIA-NASA vs 9 random letters)
3. **Manipulation** — Not just storage: mental arithmetic, planning, reasoning happen here

## Why It's So Small
- Metabolically expensive (prefrontal cortex uses ~disproportionate glucose)
- Constraint forces prioritization → better decision-making
- Evolutionary: You need to act NOW on limited info, not buffer everything
