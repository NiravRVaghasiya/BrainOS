# 🛠️ Practical Memory Techniques

## Why These Work (Neuroscience → Technique Mapping)

| Brain Principle | Technique That Exploits It |
| --- | --- |
| Hippocampal pattern completion | Method of Loci (spatial cues trigger full recall) |
| Ebbinghaus forgetting curve | Spaced Repetition (intervene at optimal decay points) |
| Retrieval strengthens traces | Active Recall / Testing Effect (practice remembering) |
| Depth of processing → stronger LTP | Elaborative Encoding (connect to meaning) |
| Theta-gamma coupling (WM capacity) | Chunking (compress multiple items into single slots) |
| Sleep consolidation (SWS replay) | Sleep-Optimized Study Schedule |
| Emotional tagging (amygdala boost) | Emotional Encoding (make it vivid, personal) |
| Dual coding (verbal + visual) | Visual Mnemonics (images + words together) |
| Schema-assisted consolidation | Prior Knowledge Activation (connect new → old) |
| DMN incubation | Strategic Breaks (let the default mode network work) |
| Interleaving forces discrimination | Interleaved Practice (mix topics, don't block) |
| State-dependent retrieval | Context Matching (study in test-like conditions) |

## The Optimal Study Session (Combining Techniques)

```
┌─────────────────────────────────────────────────────────────────┐
│                   THE IDEAL 50-MINUTE STUDY BLOCK                │
│                                                                  │
│  MINUTE 0-2:   PRIME (activate prior knowledge — what do I      │
│                already know about this topic? Schema activation)  │
│                                                                  │
│  MINUTE 2-25:  ENCODE (new material — elaborative, questioning, │
│                dual coding, connecting to existing knowledge)     │
│                                                                  │
│  MINUTE 25-35: RETRIEVE (close notes, recall everything you can,│
│                write/sketch from memory, identify gaps)           │
│                                                                  │
│  MINUTE 35-45: REVIEW GAPS (open notes, target ONLY what you    │
│                couldn't recall — targeted re-encoding)            │
│                                                                  │
│  MINUTE 45-50: SPACE (schedule next review — when will you test  │
│                yourself again? Add to SRS. Plan interleaving.)    │
│                                                                  │
│  THEN: 10-min BREAK (walk, no screens — let DMN consolidate)    │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

```
