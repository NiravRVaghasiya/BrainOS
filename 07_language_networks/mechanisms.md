# ⚙️ Language Networks — Mechanisms

## Dual Stream Model (Hickok & Poeppel, 2007)

```
AUDITORY INPUT
      ↓
Superior Temporal Gyrus (phonological analysis)
      ↓
┌─────────────────┬──────────────────┐
│  VENTRAL STREAM │  DORSAL STREAM   │
│  (What pathway) │  (How pathway)   │
│                 │                  │
│  Sound → Meaning│  Sound → Motor   │
│  Comprehension  │  Repetition      │
│  Lexical access │  Articulation    │
│                 │                  │
│  Temporal lobe  │  Parietal → Frontal│
│  → Anterior     │  → Premotor      │
│    Temporal     │  → Broca's area  │
└─────────────────┴──────────────────┘
```

## How Words Are Stored (The Mental Lexicon)

### Structure: Multi-Layered Network
```
PHONOLOGICAL LAYER:  /kæt/ — sound pattern
        ↕
ORTHOGRAPHIC LAYER:  C-A-T — spelling pattern
        ↕
SEMANTIC LAYER:      [furry][pet][meows][animal] — meaning features
        ↕
SYNTACTIC LAYER:     [noun][countable][animate] — grammar tags
        ↕
MOTOR LAYER:         [jaw, tongue, larynx programs] — articulation
```

### Each word = a node connected at ALL layers simultaneously
- Hearing "cat" activates phonological → spreads to semantic → primes "dog", "pet", "meow"
- Reading "cat" activates orthographic → same spread
- Damage at different layers → different deficits

## How Sentences Are Processed

### Incremental Parsing (word-by-word):
1. Each word arrives → immediate integration attempt
2. Working memory holds current parse structure
3. **Garden-path sentences**: "The horse raced past the barn fell" — initial parse FAILS → reanalysis
4. Syntax and semantics interact in REAL-TIME (not sequentially)

### Prediction (The Brain Gets Ahead):
- After "The pizza was too hot to ___" → brain PRE-ACTIVATES "eat" before you hear it
- N400 ERP component: Large when word is unpredictable, small when predicted
- Language comprehension is largely PREDICTION + error correction
- Similar to motor system: Forward model predicts next word

## How New Words Are Learned

### The Complementary Learning Systems:
1. **Fast mapping** (hippocampus): Single exposure creates a fragile, context-dependent trace
2. **Slow consolidation** (temporal cortex): Repeated exposure → context-free, stable lexical entry
3. **Integration**: After sleep, new word integrates with existing lexicon (competes in recognition)

### Evidence:
- Learn "cathedruke" (novel word): Next day it interferes with "cathedral" recognition
- Sleep is REQUIRED for this integration (no interference without sleep)
- Proves: New vocabulary needs consolidation to become truly "lexicalized"

## Grammar: Procedural Memory System
- Grammar rules are IMPLICIT — native speakers can't state them but use them perfectly
- Stored in basal ganglia (same system as motor habits!)
- Evidence: Parkinson's patients (basal ganglia damage) have grammar difficulties
- Regular past tense ("-ed") = procedural rule application
- Irregular past tense ("went", "sang") = declarative memory (memorized forms)
