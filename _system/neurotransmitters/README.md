# 🧪 Neurotransmitters — The Signaling Chemicals

| Transmitter | Memory Role | Too Little | Too Much |
|-------------|-------------|-----------|----------|
| **Acetylcholine** | Encoding new memories, attention | Alzheimer's (memory loss) | Overstimulation |
| **Dopamine** | Reward-based learning, motivation | Can't learn from reward | Addiction, mania |
| **Norepinephrine** | Alertness, emotional memory boost | Inattention | Anxiety, hypervigilance |
| **Serotonin** | Mood regulation, memory modulation | Depression, impaired recall | Serotonin syndrome |
| **Glutamate** | LTP (the main "strengthen synapse" signal) | Can't form memories | Excitotoxicity (cell death) |
| **GABA** | Inhibition, noise reduction, sleep | Seizures, anxiety | Sedation, amnesia |

## Key for learning:
- **Dopamine prediction error**: Unexpected reward → dopamine surge → learning signal
- **Acetylcholine + attention**: ACh release in hippocampus = "record this"
- **Norepinephrine + emotion**: NE flood during stress = "this is important, remember it"
