# 🤸 Motor Memory — The Cerebellum

> The body's autopilot — timing, coordination, and fine motor sequences.

## Cerebellum Facts:
- Contains ~50% of all neurons in the brain (despite being ~10% of volume)
- Specializes in TIMING and SEQUENCING
- Operates below conscious awareness

## What it stores:
- Motor programs (the exact muscle sequence to throw a ball)
- Timing calibration (when to activate which muscle, for how long)
- Error correction models (predicted vs. actual → adjust)
- Posture and balance algorithms

## Learning mechanism: Error-driven
1. Attempt movement
2. Compare outcome to intended outcome
3. Adjust internal model (climbing fiber signals → Purkinje cell modification)
4. Repeat until error ≈ 0

## Durability: Extremely long-lasting
- Muscle memory after years of not practicing still partially intact
- "It's like riding a bike" is literally true — cerebellum retains the program

## Offline consolidation:
- Motor skills IMPROVE after sleep without additional practice
- The brain optimizes motor programs during offline replay
