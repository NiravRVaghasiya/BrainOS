# 😴 Sleep & Memory Consolidation

> Sleep is when the brain converts short-term patterns into permanent storage.

## The Night Shift:

### Stage N3 (Deep / Slow-Wave Sleep) — "Transfer"
- Hippocampal sharp-wave ripples replay the day's experiences
- Cortex receives and starts integrating
- Most important for: Declarative memory (facts, events)

### REM Sleep — "Integrate & Emotionally Process"
- Dreams integrate new memories with existing knowledge
- Emotional charge is reduced (you remember WHAT happened but feel less about it)
- Most important for: Procedural memory, creativity, emotional regulation

## Evidence:
- Sleep deprivation → 40% drop in memory formation
- Naps after learning → better retention vs. staying awake
- "Sleeping on a problem" → Insight (solutions appear after sleep)

## Practical implications:
- Study before sleep (not morning) for best retention
- Don't pull all-nighters before exams
- Spaced repetition + sleep between sessions = optimal
