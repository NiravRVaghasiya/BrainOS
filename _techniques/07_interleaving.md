# 🔀 Interleaving — Mix It Up for Better Learning

> Studying Topic A, then B, then C (blocked) FEELS easier.
> Studying A-B-C-A-C-B-A-B-C (interleaved) IS harder — and that's why it works.

## The Neuroscience Behind It

### Why Mixing Topics Beats Blocking:

**1. Forces Discrimination (Pattern Separation)**
- Blocked: All examples of Type A together → brain never needs to DISTINGUISH types
- Interleaved: A-B-A-C-B → brain MUST identify "what makes A different from B?"
- This activates hippocampal pattern separation → more distinctive memory traces

**2. Strengthens Retrieval (Each Switch = Mini Recall)**
- Switching from B back to A requires RETRIEVING A's strategy from memory
- Each switch = a retrieval practice opportunity (testing effect bonus)
- Blocked practice: Just repeat → no retrieval needed

**3. Builds Flexible Transfer**
- Real life NEVER presents problems in neat blocks
- Interleaving trains: "First, identify WHAT TYPE of problem this is"
- This diagnostic skill is critical but never practiced during blocked study

**4. Induces Desirable Difficulty**
- Interleaving is HARDER (lower performance during practice)
- But harder practice = stronger learning (desirable difficulty principle)
- Students consistently PREFER blocking but LEARN more from interleaving

## The Evidence

```
EXPERIMENT (Rohrer & Taylor, 2007):

Students learned to calculate volumes of 4 different 3D shapes.

GROUP A (BLOCKED):           GROUP B (INTERLEAVED):
Practice 10 cylinders        Practice: cyl, cone, sphere, cyl,
Practice 10 cones            wedge, cone, sphere, cyl, cone...
Practice 10 spheres          (same total practice, mixed order)
Practice 10 wedges

RESULTS (test 1 week later):
  Blocked:      ████████████░░░░░░░░░░░░░░  ~38% correct
  Interleaved:  ██████████████████████░░░░░  ~72% correct

  NEARLY DOUBLE the performance from interleaving!
  
KEY: During PRACTICE, blocked group performed BETTER (felt easier).
     On the DELAYED TEST, interleaved group crushed it.
     What feels easy during practice ≠ what produces durable learning.
```

## How to Interleave (Practical Guidelines)

### Rule 1: Interleave RELATED Topics (Not Random)
```
GOOD INTERLEAVING (related, confusable categories):
  • Math: Integration by parts → U-substitution → Partial fractions → repeat
  • Medicine: Similar-looking skin conditions → discriminate between them
  • Language: Similar verb conjugations → past vs imperfect vs conditional
  • Music: Similar-tempo pieces in different keys

BAD INTERLEAVING (too different, nothing to discriminate):
  • Math → then History → then Chemistry → then Math
  • (These don't share features that need discrimination)
  • (Exception: This still provides spacing benefit, just not interleaving benefit)
  
THE PRINCIPLE: Interleave things you need to DISTINGUISH between.
```

### Rule 2: The ABA Pattern (Minimum Interleaving)
```
BLOCKED:       AAAAAA → BBBBBB → CCCCCC
INTERLEAVED:   ABC → ABC → ABC → ABC → ABC → ABC

MINIMUM EFFECTIVE PATTERN:
  Do 2-3 problems of Type A → Switch to 2-3 of Type B → Switch to C → Back to A
  
  You DON'T need to switch after every single problem.
  Switching every 2-4 examples is sufficient for the discrimination benefit.
```

### Rule 3: Start Blocked, Move to Interleaved
```
DAY 1 (New material): BLOCKED
  Learn Type A until you understand the basic pattern
  Learn Type B until you understand the basic pattern
  Learn Type C until you understand the basic pattern
  (Need some initial fluency before mixing helps)

DAY 2+: INTERLEAVED
  Practice all types mixed together
  (Now the discrimination training kicks in)
  
ANALOGY: Learn each instrument's part separately first,
         THEN practice playing together in the ensemble.
```

## When Interleaving Works BEST

| Domain | Interleave Between | Effect |
|--------|-------------------|--------|
| Math | Problem types requiring different strategies | ★★★★★ |
| Art | Painting styles (Monet vs Renoir vs Degas) | ★★★★★ |
| Medicine | Similar diagnoses (discriminating symptoms) | ★★★★★ |
| Sports | Different shot types (tennis: serve, volley, baseline) | ★★★★☆ |
| Music | Similar pieces or techniques | ★★★★☆ |
| Language | Similar grammatical structures | ★★★★☆ |
| Science | Categorization problems (which formula applies?) | ★★★★☆ |

## When NOT to Interleave

```
✗ Completely new material (need blocked practice to build initial schema)
✗ Unrelated subjects (no discrimination benefit — just use spacing instead)
✗ Motor skills in earliest acquisition (need massed repetition to establish basic motor program)
✗ When you can't even DO the task yet (interleaving assumes basic competence)
```
