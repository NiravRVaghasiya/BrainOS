# 💾 Long-Term Memory — Permanent Storage

> Capacity: Effectively unlimited (~2.5 petabytes estimated)
> Duration: Days → Entire lifetime
> Encoding: Distributed across neocortex as synaptic weight patterns

## The Two Major Systems

```
Long-Term Memory
├── EXPLICIT (Declarative) — "Knowing THAT"      [Hippocampus-dependent]
│   ├── Episodic  — Personal events, autobiography
│   └── Semantic  — Facts, concepts, language
│
└── IMPLICIT (Non-declarative) — "Knowing HOW"   [Hippocampus-independent]
    ├── Procedural    — Skills, habits (basal ganglia)
    ├── Priming       — Perceptual facilitation (cortex)
    ├── Conditioning  — Learned associations (amygdala/cerebellum)
    └── Non-associative — Habituation, sensitization
```

## Key Insight: These Are SEPARATE SYSTEMS
- Patient H.M. lost episodic/semantic formation but could still learn motor skills
- Alzheimer's destroys semantic before procedural (can't name objects but can play piano)
- Amnesiacs show priming effects despite having zero conscious recall

## How Storage Works Physically
1. **Synaptic strengthening** — LTP (Long-Term Potentiation): repeated firing → stronger connection
2. **Structural changes** — New dendritic spines grow, synapses enlarge
3. **Protein synthesis** — Genes activated to produce structural proteins that stabilize the change
4. **Network integration** — New memory woven into existing knowledge web (schema assimilation)
