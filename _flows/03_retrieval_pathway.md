## Retrieval Modes

### Mode 1: Direct / Automatic Retrieval
```
Strong cue → Immediate, effortless activation
No search required. Pattern completes instantly.

Cue: "What's 2 + 2?"
     ↓ (immediate)
Answer: "4" — stored as semantic fact, retrieval is reflexive

Cue: First notes of "Happy Birthday"
     ↓ (instant)  
Answer: Full melody plays in your mind

Neural: Strong synaptic pathways fire without hippocampal mediation
        (fully consolidated semantic/procedural traces)
```

### Mode 2: Strategic / Effortful Retrieval
```
Weak cue → Active search process → Generate candidates → Evaluate

Cue: "What did you have for lunch last Tuesday?"
     ↓
Search: Where was I? (office → cafeteria). What day was it? (Tuesday = 
        usually pasta day?). Who was I with? (alone? meeting?)
     ↓
Generate: "I think it was pasta... or maybe the sandwich..."
     ↓
Evaluate: "Yes, pasta — because I remember spilling sauce on my shirt"
     ↓
Output: Reconstructed memory (confidence: moderate)

Neural: Prefrontal cortex drives hippocampal search.
        Multiple candidates generated, frontal monitoring selects best match.
```

### Mode 3: Involuntary / Spontaneous Retrieval
```
No intentional search — memory pops up unbidden

Trigger: Random smell, unexpected context match, emotional resonance
     ↓
Activation: Hippocampus auto-completes pattern from incidental cue
     ↓
Experience: Vivid, emotional, feels like "being there again"
     ↓
Often: More vivid and emotional than deliberate recall
       (because it bypasses prefrontal filtering/monitoring)

Example: Proust's madeleine, PTSD flashbacks, déjà vu
```

## The Neural Mechanics of Retrieval

```
┌─────────────────────────────────────────────────────────────────┐
│                     RETRIEVAL NETWORK                             │
│                                                                   │
│  PREFRONTAL CORTEX (strategic control)                           │
│  ├── Left VLPFC: Generates retrieval cues ("search with THIS")   │
│  ├── DLPFC: Monitors output ("is this correct? complete?")       │
│  └── Anterior PFC: Source monitoring ("WHERE did I learn this?") │
│                          ↓  ↑                                     │
│  HIPPOCAMPUS (pattern completion engine)                          │
│  ├── CA3: Receives partial cue → completes full pattern           │
│  ├── CA1: Compares retrieved pattern with current reality         │
│  └── Sends reactivation signals to cortex                        │
│                          ↓                                        │
│  NEOCORTEX (content storage)                                      │
│  ├── Visual cortex: Reactivates visual components                 │
│  ├── Auditory cortex: Reactivates sounds                          │
│  ├── Motor cortex: Reactivates action sequences                   │
│  └── Emotional cortex: Reactivates feelings                       │
│                                                                   │
│  RESULT: Distributed re-activation = conscious "re-experience"    │
│                                                                   │
└─────────────────────────────────────────────────────────────────┘
```

## Retrieval Success Factors

### 1. Cue-Trace Overlap (Encoding Specificity)
```
ENCODING:   [Context A] + [Mood X] + [Content] → STORED
RETRIEVAL:  [Context A] + [Mood X] → matches → SUCCESS ✓
RETRIEVAL:  [Context B] + [Mood Y] → mismatch → FAILURE ✗

The MORE overlap between encoding cues and retrieval cues → better recall
```

### 2. Trace Strength (Practice Effects)
```
Weak trace (encoded once):     ░░░██░░░░░  → Needs strong cue to activate
Strong trace (encoded 10x):    ████████░░  → Weak cue is sufficient
Very strong (encoded 100x+):   ██████████  → Almost any related cue works
                                              (even spontaneous activation)
```

### 3. Interference at Retrieval
```
Target memory: "My current password is X47blue"
Competitors:   "My old password was Fish99red"
               "My work password is Admin2024"
               
All activate simultaneously → Competition → Response conflict
Winner determined by: Recency, Frequency, Context match
Loser = temporarily INHIBITED (retrieval-induced forgetting)
```

### 4. State-Dependent Retrieval
```
Encoded in state A → Retrieved best in state A

States include:
• Physical state (caffeine, alcohol, exercise level)
• Emotional state (happy, sad, anxious)
• Physiological state (time of day, hunger, fatigue)
• Environmental state (location, sounds, smells)
• Cognitive state (what else you were thinking about)
```

## Retrieval Changes the Memory (Reconsolidation)

```
BEFORE RETRIEVAL:     Memory is STABLE (consolidated, dormant)
                           ↓
DURING RETRIEVAL:     Memory becomes LABILE (unstable, modifiable)
                      ~4-6 hour window of vulnerability
                           ↓
AFTER RETRIEVAL:      Memory RE-CONSOLIDATES in modified form
                      (new version becomes the "permanent" record)

IMPLICATIONS:
• Every recall slightly ALTERS the memory
• Post-retrieval information can CONTAMINATE the original
• Therapeutic potential: Recall trauma + intervention → weaken the trace
• Memory is a Wikipedia article, not a photograph — edited with each access
```

## Retrieval Pathways by Memory Type

| Memory Type | Retrieval Pathway | Conscious? | Speed |
|-------------|------------------|-----------|-------|
| Episodic | Hippocampus → distributed cortex → PFC monitoring | Yes, effortful | 500ms-seconds |
| Semantic | Direct cortical access (temporal poles) | Yes, automatic | 200-400ms |
| Procedural | Basal ganglia → motor cortex (context-triggered) | No | <100ms |
| Priming | Reduced firing in sensory cortex (familiarity signal) | No | <200ms |
| Conditioning | Amygdala/cerebellum → automatic response | No | <50ms (fear) |

## The Feeling of Knowing (Metacognition)

```
"I KNOW I know this..." (Tip-of-tongue state)
     ↓
Partial activation detected by Anterior PFC
     ↓
Generates "feeling of knowing" signal WITHOUT full retrieval
     ↓
This signal is USUALLY accurate (you DO know it — just can't access it NOW)
     ↓
Resolution: 
• Wait (spreading activation may reach threshold)
• Change cues (approach from different angle)
• Sleep on it (offline reactivation may unlock)
• External cue (see the answer → "YES! That's it!")
```
