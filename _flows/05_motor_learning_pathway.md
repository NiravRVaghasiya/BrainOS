## Cerebellar Fine-Tuning (Runs in Parallel)

```
FOR EVERY MOVEMENT ATTEMPT:

CORTEX sends copy of motor command → CEREBELLUM (via pontine nuclei)
                                         ↓
                               CEREBELLAR FORWARD MODEL
                               "If this command executes,
                                the outcome should be..."
                                         ↓
                                    PREDICTION
                                         ↓
                              Compare with ACTUAL outcome
                              (from sensory feedback)
                                         ↓
                          ┌──────────────────────────────┐
                          │  ERROR = Predicted - Actual   │
                          └──────────────┬───────────────┘
                                         ↓
                          ┌──────────────────────────────┐
                          │  Climbing fiber → Purkinje    │
                          │  cell → UPDATE internal model  │
                          └──────────────────────────────┘
                                         ↓
                          Next attempt is more accurate ✓

This runs THOUSANDS of times until error ≈ 0
Then: Movement is calibrated. Cerebellum runs it on autopilot.
```

## Sleep's Role in Motor Consolidation

```
DAY 1: Practice piano sequence (4-1-3-2-4)
        ↓ Performance plateau (can't get faster despite trying)
        
NIGHT: Sleep
        ↓ Stage 2 NREM spindles (12-15 Hz) over motor cortex
        ↓ Motor cortex replays the sequence offline
        ↓ Unnecessary co-contractions removed
        ↓ Transitions between notes smoothed
        
DAY 2: Performance is 20-30% BETTER without additional practice!
        ↓ "Sleep improvement" — the brain optimized offline
        
This does NOT happen if you stay awake for the same duration.
Sleep is REQUIRED for motor memory optimization.
```

## The Chunking Process (How Sequences Become Units)

```
EARLY LEARNING (individual elements):
  [press A] → pause → [press B] → pause → [press C] → pause → [press D]
  
CHUNKING (elements merge into units):
  [A-B] → pause → [C-D]
  
ADVANCED CHUNKING (units merge into super-units):
  [A-B-C-D] ← entire sequence is ONE "chunk" now
  
TIMING SIGNATURE:
  Early:    A....B....C....D    (inter-element pauses = long, uniform)
  Chunked:  AB..CD              (intra-chunk gaps tiny, inter-chunk gaps remain)
  Expert:   ABCD                (whole thing fires as unit, no internal gaps)
  
Hierarchical: Chunks of chunks of chunks
Piano sonata = sections → phrases → bars → notes
Each level is a single "unit" at its hierarchical level
```
