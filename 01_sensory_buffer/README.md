# 👁️ Sensory Buffer (Sensory Memory)

> The brain's "raw footage" — everything hits here first, but only for milliseconds.

## What It Is
The initial landing zone for ALL incoming sensory data. Massive bandwidth, nearly zero retention.

## Duration: 200ms – 3 seconds

## Types
| Buffer | Sense | Duration | Capacity |
|--------|-------|----------|----------|
| Iconic | Vision | ~250ms | Entire visual field |
| Echoic | Hearing | ~3-4s | Last few seconds of sound |
| Haptic | Touch | ~2s | Current tactile state |

## Key Insight
You "see" the entire room but only **attend** to a fraction. The rest decays instantly.
The sensory buffer is why you can "replay" a sentence someone said even if you weren't 
paying attention — but only for ~3 seconds.

## Bottleneck: The Attention Gate
Only what passes through **selective attention** moves to working memory.
Everything else is discarded — never encoded, never stored.
